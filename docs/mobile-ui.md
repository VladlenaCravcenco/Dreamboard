# Мобильный интерфейс

## Аудит и принятые решения

Исходные маршруты сохранены: `/` (мечты), `/dream/:id`, `/completed`,
`/stats`, `/friends`, `/friends/:id`, `/share`, `/profile`, публичные
`/auth`, `/reset-password`, `/invite/:token`, `/u/:slug`.
`/card` и `/reminders` остаются под существующими feature flags.
Отдельной главной и состояния «заморожено» в текущем интерфейсе нет:
новые сущности и вымышленные данные не добавлялись.

Вместо верхних вкладок сайта на телефоне используются пять постоянных
разделов: Мечты, Сбылось, Друзья, Прогресс, Профиль. Создание — отдельное
действие. Фокус доски — первый незавершённый шаг, если он существует;
основной контент — мечты, вторичный — категории и счётчики.
В деталях фокус — цель и её шаги; удаление отделено от завершения.
В статистике главный блок — доля сбывшихся мечт.

## Реализация

- `Layout`: flex-каркас на `100dvh`, отдельный scroll-контейнер, safe areas,
  нижние подписанные вкладки, сохранение прокрутки по маршрутам.
- `mobile.css`: отдельная композиция до 767 px, различимые поверхности,
  светлая/тёмная палитра, цели касания основных кнопок 48 px.
- `MainScreen` / `DreamCard`: список вместо тесной сетки, следующий шаг,
  подпись состояния и числа шагов, индикатор накоплений;
  поиск и категория сохраняются в sessionStorage.
- `DetailScreen`: просторные группы, область касания checkbox 48 px,
  постоянный label описания и отдельное удаление.
- `AddDreamModal`: полноэкранная форма на телефоне без автоматического
  открытия клавиатуры, десятичный ввод бюджета. Черновик сохраняется
  при закрытии, пока компонент остаётся на странице.
- Общие Radix dialogs на телефоне отображаются как прокручиваемые sheets.
- Старые конфликтующие мобильные правила удалены; desktop-сетка сохранена.

Авторизация, серверные операции, модель данных, фото, бюджет, завершение,
друзья и обмен списками не заменялись.

## Проверка

- `npm run build`: успешно (существует предупреждение размера JS >500 kB).
- `npm test`: 15/15.
- Изолированный preview через `tests/build-preview.mjs`, без реального аккаунта:
  создание, открытие, добавление/отметка шага, возврат, переходы вкладок.
- Chromium: 320, 390, 430, 768, 1280 px — нет горизонтального overflow;
  мобильная навигация скрыта начиная с 768 px, desktop имеет 3/4 колонки.
- Светлая/тёмная тема, скриншоты; ошибок JavaScript в проверенных сценариях нет.

Не проверено на физических iOS/Android: системная клавиатура, реальные
safe-area inset, системный Back, увеличение системного шрифта. Native
Capacitor-контейнера в репозитории нет. Полный accessibility-аудит,
сетевые ошибки реального backend и все интеграции в эту браузерную
проверку не входили. Публикация не выполнялась.
